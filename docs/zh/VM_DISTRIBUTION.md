# Ubuntu 虚拟机发布方案

状态：计划中，尚未导出或上传镜像。

可以分享预装环境。当前为 Ubuntu 24.04.5 ARM64，需要兼容的 ARM64 主机和虚拟化软件；普通 x86 电脑不能直接通用，需要另建对应环境。

| 发布位置 | 内容 |
|---|---|
| GitHub 仓库 | 代码、中英文文档、配置、环境版本清单 |
| Release 或外部下载地址 | 压缩虚拟机、SHA-256、导入说明 |
| 独立数据下载 | 示例 ROS + ULog 实验包 |

镜像不提交到 Git 历史。导出后根据文件大小和平台当前限制选择 Release 或外部托管。

发布步骤：复制一份专用发布虚拟机 → 清除个人文件、浏览器登录、API key、token、SSH 密钥等 → 记录架构、虚拟机格式、CPU/RAM/磁盘、软件版本和上游许可 → 关机打包并生成校验值 → 重新导入验证 → 发布下载地址。

导入测试需验证 PX4/Gazebo、8888 桥、`/clock`、一次任务、ROS 数据、logger 关闭与 ULog 归档。测试通过后再声明可直接导入使用；不把个人工作虚拟机原样公开。
