## 3. 说明与限制

- 阶段耗时使用 `events.csv` 的 `wall_elapsed_s`；A/B 误差使用状态切换前、字段有效且 freshness 在约定窗口内的 PX4 local NED 样本。NaN 未填 0。
- 候选 10 次均有 estimator reset，部分运行有 preflight 或 freshness 标记；这些作为环境协变量保留，不能直接归因于参数，也不自动否定已可计算的任务指标。
- A 点误差增加约 36%，B 点误差下降约 20%，因此本批任务表现判定为 `not_improved`。这不是统计显著性结论，也不能单凭它证明参数的严格因果作用。
- 本科目没有生成额外图表：A/B 两项核心误差和阶段耗时表已经能直接表达结论，避免用图表掩盖 ULog/ROS 时间线限制。

## 4. 结论

`MPC_XY_VEL_P_ACC=1.900` 在科目 3 中保持了任务完成和降落可靠性，但 A 点误差明显增大，A/B 没有同时改善，因此本轮候选结论为 **`not_improved`**。建议将参数回退至 `1.800`；该回退是建议，尚未在本报告中执行。
